## 🎨 2. Overlays OBS/Streamlabs : Créer un Habillage Professionnel

Un overlay est une couche graphique superposée à votre gameplay ou contenu. En 2026, **73 % des viewers interrogés déclarent rester plus longtemps sur un stream avec un habillage visuel cohérent**, contre un stream sans overlay [Source 2]. C'est le premier levier d'amélioration de votre présentation.

### 2.1 Les Composants Essentiels d'un Overlay

Un habillage de stream complet comprend :

- **Cadre webcam** : Encadre votre caméra, intégré à la charte graphique
- **Barre d'informations** : Affiche pseudo, derniers abonnés, objectifs de sub
- **Panneau de chat** : Intègre les messages du chat directement dans la scène
- **Alertes de donation/sub** : Animations déclenchées par les interactions
- **Panneau "Now Playing"** : Affiche le titre de la musique en cours
- **Compteurs de progression** : Objectifs d'abonnés, heures streamées

> 💡 **Principe fondamental** : Un bon overlay ne distrait pas — il **complète** votre contenu. Limitez-vous à 20–25 % de l'écran occupé par les éléments graphiques. Au-delà, vous gênez la lisibilité.

### 2.2 Créer un Overlay sur OBS Studio

**Sans plugin, directement dans OBS :**

1. **Créez une nouvelle scène** : Panneau Scènes → "+" → "Stream Principal"
2. **Ajoutez vos sources dans l'ordre** (bas = derrière, haut = devant) :
   - Capture de jeu (en bas)
   - Webcam (au-dessus du jeu)
   - Image PNG d'overlay (transparente, au-dessus de tout)
3. **Verrouillez les sources** une fois positionnées : clic droit → Verrouiller
4. **Utilisez les guides d'alignement** : Affichage → Guides d'alignement, grille de scène

**Pour des overlays animés** : Ajoutez une **source Navigateur** (Browser Source) avec une URL pointant vers une ressource HTML/CSS animée (StreamElements, Streamlabs Widget).

## 🎬 3. Transitions OBS : Fluidifier le Passage entre Scènes

Une transition fluide entre vos scènes (gameplay → cam → jingle) est le marqueur d'un stream professionnel. En 2026, OBS Studio 30.x intègre des transitions avancées nativement [Source 3], mais rares sont les streamers qui les utilisent correctement.

### 3.1 Les Types de Transitions Disponibles dans OBS

**Transitions natives OBS :**
- **Fondu enchaîné** (*Fade*) : La plus classique, douce et universelle
- **Couper** (*Cut*) : Instantané, idéal pour les changements rapides
- **Balayage** (*Slide*) : La scène entre depuis un côté
- **Déplacement** (*Luma Wipe*) : Masque animé personnalisable avec une image en niveaux de gris
- **Stinger** : Vidéo MP4/WebM utilisée comme transition animée (le plus pro)

### 3.2 Créer une Transition Stinger (Niveau Pro)

La **transition Stinger** est utilisée par 90 % des streamers partenaires Twitch [Source 2]. Elle consiste en une courte animation vidéo (~1 seconde) qui couvre l'écran pendant le changement de scène.

**Comment l'ajouter dans OBS :**

1. Panneau **Transitions de scène** → "+" → **Stinger**
2. Choisissez votre fichier vidéo (MP4, WebM avec transparence de préférence)
3. Réglez le **Point de transition** : généralement 50 % (milieu de l'animation)
4. **Durée** : 800 ms à 1 200 ms est la plage optimale
5. **Surveillez le son** : désactivez l'audio de transition si votre vidéo n'est pas censée avoir de son

**Sources de transitions Stinger gratuites :** nerdordie.com/free-twitch-transitions, streamelements.com/overlay-editor

### 3.3 Paramétrer les Transitions par Scène

OBS permet d'assigner une **transition différente à chaque changement de scène** :

1. Clic droit sur une scène → **Transition de scène par défaut**
2. Choisissez la transition et sa durée spécifiquement pour ce passage
3. Exemple : Fondu lent (600 ms) de "Gameplay" vers "BRB", Stinger vers "Starting Soon"

> ⚠️ **Erreur courante** : Ne pas synchroniser la durée de la transition avec le tempo de votre musique de fond. Une transition à 800 ms sur un fond musical à 120 BPM (500 ms par temps) crée un décalage perceptible par l'audience.

## 🔔 4. Alertes Stream : Engager et Fidéliser en Temps Réel

Les alertes sont des animations déclenchées automatiquement lors d'événements : nouvel abonné, donation, raid, follow. Bien configurées, elles transforment chaque interaction en moment de célébration partagée. Mal configurées, elles deviennent du bruit visuel et sonore.

### 4.1 Configurer les Alertes dans Streamlabs

Streamlabs propose un système d'alertes intégré, synchronisé avec Twitch, YouTube et Kick [Source 4] :

1. Dans Streamlabs Desktop → **Alert Box** → Ajoutez une source "Alert Box" dans OBS
2. Ou utilisez **streamlabs.com/alert-box** directement comme Browser Source dans OBS Studio
3. **Configurez chaque type d'alerte** : follow, sub, resub, bits, donation, raid, host

**Paramètres recommandés pour chaque alerte :**

| Type d'alerte | Durée affichage | Volume son | Animation |
|---|---|---|---|
| Follow | 4–5 secondes | 50 % | Légère (fade in/out) |
| Abonnement | 6–8 secondes | 70 % | Dynamique |
| Donation | 8–10 secondes | 70 % | Forte + TTS |
| Raid | 10–15 secondes | 80 % | Spectaculaire |
| Bits (Cheers) | 5–7 secondes | 60 % | Selon montant |

### 4.2 Personnaliser les Alertes avec StreamElements

**StreamElements** est l'alternative à Streamlabs, avec un éditeur d'alertes très puissant [Source 4] :

1. **streamelements.com** → Mes overlays → Nouvelle alerte
2. Choisissez une animation de base (drop in, zoom, flip, custom)
3. Personnalisez : image, son, texte, couleurs, durée, conditions
4. Copiez l'URL de widget → OBS → Sources → Navigateur → Collez l'URL

**Fonctionnalités avancées 2026 :**
- **Alertes conditionnelles** : Son différent selon le montant (10€ vs 100€ de donation)
- **File d'alertes** : Gère les alertes simultanées sans superposition
- **Variation aléatoire** : 3-5 animations différentes pour le même type d'événement (évite la répétition)

### 4.3 Charte Graphique des Alertes

L'erreur des débutants : utiliser des alertes qui ne correspondent pas à leur univers graphique. **Règle des 3 cohérences :**

- **Palette de couleurs** : Maximum 3 couleurs, identiques à votre overlay
- **Typographie** : Même police que votre branding, ou au moins la même famille
- **Ambiance sonore** : Sons d'alertes en accord avec votre contenu (gaming, musique, talk show)

> 💡 **Astuce pro** : Créez des alertes spéciales pour les grands événements (raids de 50+ viewers, donations de 50€+) avec des animations plus spectaculaires. La variation maintient l'intérêt de votre communauté.

## ⏸️ 5. Écrans BRB et Starting Soon : Professionnaliser vos Pauses

Les écrans de transition — **BRB** (*Be Right Back*), **Starting Soon**, **Ending Soon** — sont souvent négligés. Pourtant, ils représentent une opportunité unique : **garder vos viewers engagés même quand vous n'êtes pas actif**.

### 5.1 L'Écran "Starting Soon" : La Première Impression

L'écran Starting Soon s'affiche avant que vous commenciez votre stream. C'est la **première image que voient vos viewers** en arrivant sur votre chaîne.

**Éléments essentiels d'un bon Starting Soon :**
- **Compte à rebours animé** : Donne une indication de l'heure de début (via StreamElements Countdown Widget)
- **Musique de fond** : Lo-fi, chiptune ou ambiance en accord avec votre contenu
- **Liste de l'ordre du jour** : Annoncez ce que vous allez faire (jeu, rubrique, etc.)
- **Réseaux sociaux** : Invitez à vous suivre en attendant
- **Animation de fond** : Particules, boucle vidéo, gradient animé — évitez l'image fixe

**Comment créer un Starting Soon dans OBS :**

1. Créez une scène dédiée : "Starting Soon"
2. Ajoutez une **source vidéo** (Media Source) avec votre fond animé en boucle
3. Ajoutez une **source Navigateur** pour le compte à rebours StreamElements
4. Ajoutez votre musique via une **source Média** avec une playlist en boucle
5. Positionnez textes et logos via des **sources Image** et **sources Texte**

### 5.2 L'Écran BRB : Fidéliser Pendant les Pauses

**BRB** (*Be Right Back* = "Je reviens tout de suite") est affiché lors des pauses techniques ou personnelles. Bien conçu, il retient jusqu'à **40 % de viewers supplémentaires** pendant une pause de 5 minutes, comparé à un écran vide [Source 2].

**Éléments d'un BRB efficace :**

| Élément | Recommandation | Outil |
|---|---|---|
| Message animé | "BRB dans X minutes" avec timer | StreamElements Widget |
| Fond animé | Boucle courte 10-30 secondes | Videvo, Pixabay Video |
| Musique | Playlist lo-fi ou ambiance | Spotify (attention droits) / Monstercat |
| Chat visible | Maintenez le lien avec le chat | Browser Source chat |
| Heure de retour | Estimation précise réduit l'abandon | Texte OBS dynamique |

### 5.3 L'Écran "Ending Soon" : Clore en Beauté

Souvent oublié, l'écran **Ending Soon** annonce la fin du stream. Il est pourtant crucial pour :

- **Rediriger votre audience** : VOD à regarder, prochain stream, Discord, réseaux sociaux
- **Remercier les contributeurs** : Liste des abonnés du jour, top donations
- **Annoncer la prochaine session** : Date, heure, jeu prévu

**Structure recommandée :**
1. Animation de fin avec votre branding (même univers graphique que l'intro)
2. Tableau des "merci" : abonnés, donateurs, raiders du stream
3. "Prochain stream : [date/heure]" bien visible
4. QR code ou handles réseaux sociaux

> 💡 **Astuce** : Utilisez OBS pour déclencher automatiquement votre scène Ending Soon avec un raccourci clavier (Réglages → Raccourcis clavier → Changer de scène). Configurer Alt+E sur "Ending Soon" évite de chercher dans le panneau pendant que vous parlez à votre chat.

## ⚙️ 6. OBS vs Streamlabs : Lequel Choisir pour son Habillage ?

La question revient systématiquement dans les communautés streaming. En 2026, les deux plateformes ont leurs forces spécifiques [Source 5].

### 6.1 Tableau Comparatif OBS Studio vs Streamlabs

| Critère | OBS Studio | Streamlabs Desktop |
|---|---|---|
| **Prix** | 100 % gratuit | Gratuit (Ultra payant 19€/mois) |
| **Alertes intégrées** | Via plugins/browser source | ✅ Natif, très complet |
| **Widgets (chat, objectifs)** | Via browser source externe | ✅ Natif, interface simple |
| **Performance CPU** | ⭐⭐⭐⭐⭐ Léger | ⭐⭐⭐ Plus gourmand (~15 % CPU en plus) |
| **Personnalisation** | Illimitée (plugins, scripts) | Bonne, mais plus guidée |
| **Stabilité** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **Courbe d'apprentissage** | Moyenne | Facile |
| **Plugins disponibles** | 200+ (obs-forum.de) | Limité |
| **Multi-plateforme** | Twitch + YouTube + Kick + custom RTMP | Twitch + YouTube + Facebook |
| **Idéal pour** | Streamers avancés, PC de milieu/haut | Débutants, setup rapide |

### 6.2 Recommandation 2026

- **Débutants** → **Streamlabs Desktop** : Setup en moins de 30 minutes, alertes et widgets intégrés, interface intuitive.
- **Streamers intermédiaires/avancés** → **OBS Studio** : Performance supérieure, contrôle total, compatibilité tous services.
- **Solution hybride** → **OBS Studio + StreamElements** : Meilleure performance + alertes/widgets via browser source. C'est le setup utilisé par **62 % des streamers partenaires Twitch** [Source 5].

### 6.3 Plugins OBS Indispensables en 2026

Si vous optez pour OBS Studio, ces plugins transforment votre workflow :

- **obs-move-transition** : Animations fluides d'éléments entre scènes (gratuit, GitHub)
- **StreamFX** : Transitions et filtres avancés, flou, ombre portée (gratuit, GitHub)
- **Advanced Scene Switcher** : Changement automatique de scènes selon conditions (inactivité, jeu détecté)
- **Source Clone** : Dupliquez une source dans plusieurs scènes sans reconfiguration
- **obs-websocket** : Contrôle OBS via applications externes (Stream Deck, scripts)

# Dual PC Streaming : Configuration Optimale pour Jeux Gourmands 2026

**En 2026, les jeux AAA comme *Cyberpunk 2077 Phantom Liberty*, *Hogwarts Legacy* ou *Star Citizen* réclament 80 à 100 % des ressources CPU/GPU d'une machine haut de gamme.** Tenter de streamer dessus depuis un seul PC sans optimisation revient à demander à un sprinter de courir un 100 m avec un sac à dos plein de pierres [Source 1]. Résultat : drops de frames, stutters en direct, qualité de stream dégradée et expérience spectateur catastrophique. La solution professionnelle ? Le **dual PC streaming** — deux machines dédiées, l'une au jeu, l'autre à l'encodage. Ou, si votre budget ne le permet pas encore, un **PC unique correctement configuré** peut s'en sortir honorablement. Dans ce guide, vous découvrirez exactement comment mettre en place chaque scénario, avec les composants recommandés, les configurations logicielles étape par étape, et les astuces des streamers professionnels pour 2026.

## 🖥️ 2. Comprendre le Dual PC Streaming : Principe et Avantages

### Pourquoi les jeux AAA saturent un seul PC

Lorsqu'un jeu gourmand tourne sur votre machine, il mobilise massivement le CPU pour la physique, l'IA et les scripts de jeu, et le GPU pour le rendu graphique. En parallèle, OBS doit encoder la vidéo en H.264, HEVC ou AV1 en temps réel. Sur un processeur comme le **Ryzen 9 7950X** (16 cœurs), OBS en encodage x264 *medium* consomme environ **8 à 12 % du CPU** supplémentaire [Source 2]. Pour les jeux peu optimisés qui sollicitent déjà 90 % du CPU, le résultat est immédiatement visible : des microbégaiements (*stutters*) qui ruinent l'expérience de jeu et la qualité visuelle du stream.

### L'architecture dual PC expliquée

Un setup dual PC repose sur deux machines connectées entre elles :

1. **PC Gaming (Gaming Rig)** — joue au jeu, envoie le signal vidéo/audio au PC de streaming.
2. **PC Streaming (Encoding Rig)** — reçoit ce signal, l'encode et l'envoie sur Twitch/YouTube.

La connexion entre les deux se fait via :
- **Carte de capture HDMI** (Elgato 4K60 Pro, AVerMedia Live Gamer 4K) — câble HDMI du PC gaming vers la carte installée dans le PC streaming.
- **NDI (Network Device Interface)** — protocole réseau haute qualité, sans câble HDMI, via un switch réseau dédié ou câble Ethernet direct.

## ⚙️ 3. Configurer un Dual PC Streaming : Guide Étape par Étape

### Matériel requis pour le PC de streaming (encoding rig)

Le PC dédié à l'encodage n'a pas besoin d'être puissant pour jouer, mais il doit exceller en encodage vidéo. Voici les configurations recommandées en 2026 :

**Configuration minimale (encodage x264 *fast*, 1080p/60fps) :**
- CPU : **Intel Core i5-13400** ou **AMD Ryzen 5 7600** (6 cœurs / 12 threads)
- RAM : **16 Go DDR4/DDR5 3200 MHz**
- GPU : Quelconque (iGPU suffisant si pas de jeu sur ce PC)
- Stockage : SSD 256 Go pour l'OS
- Budget indicatif : **~400-500 €** (en recyclant un vieux boîtier/alim)

**Configuration recommandée (encodage x264 *medium*, 1440p/60fps ou AV1) :**
- CPU : **AMD Ryzen 9 7900X** ou **Intel Core i9-13900K** (12-24 cœurs)
- RAM : **32 Go DDR5 5200 MHz**
- GPU : RTX 4070 (pour encodage NVENC AV1 si souhaité)
- Budget indicatif : **~900-1200 €**

### Connexion via carte de capture HDMI

La méthode classique et la plus fiable :

1. **Installez la carte de capture** dans un slot PCIe du PC streaming (ex: Elgato 4K60 Pro MK.2 — ~180 €, AVerMedia Live Gamer 4K — ~150 €).
2. **Reliez le PC gaming au PC streaming** avec un câble HDMI 2.1 (max 4K/120fps, HDR).
3. **Configurez OBS sur le PC streaming** : ajoutez une source *Video Capture Device*, sélectionnez votre carte, réglez la résolution à 1080p ou 1440p selon votre débit montant.
4. **Ajoutez l'audio** : capturez le son de jeu via la carte de capture, ajoutez votre micro directement au PC streaming.

> **Astuce pro :** Utilisez un câble HDMI de haute qualité (certifié Ultra High Speed) pour éviter toute perte de signal. La longueur idéale est inférieure à 5 mètres [Source 3].

### Connexion via NDI (Network Device Interface)

NDI permet d'envoyer vidéo et audio via le réseau local — idéal si vos deux PC ne sont pas côte à côte ou si vous voulez éviter les câbles HDMI.

1. **Installez OBS sur le PC gaming** et activez le plugin **obs-ndi** (gratuit, disponible sur GitHub).
2. **Activez la sortie NDI** dans OBS Gaming : *Tools > NDI Output Settings > Main Output*.
3. **Sur le PC streaming**, installez aussi OBS + obs-ndi, puis ajoutez une source *NDI Source* pointant vers le PC gaming.
4. **Connectez les deux PC** via un switch Gigabit dédié ou un câble Ethernet standard direct (les cartes réseau modernes supportent l'Auto-MDI/MDIX, aucun câble croisé nécessaire).

> **Attention :** NDI consomme **environ 100-200 Mbps** de bande passante réseau. Ne pas partager ce lien avec votre réseau domestique [Source 4].

## 🚀 4. Optimiser un Single PC pour les Jeux Gourmands

### Choisir le bon encodeur matériel

Si le dual PC est hors budget, optimiser votre PC unique est la prochaine meilleure option. La clé : utiliser **l'encodeur matériel de votre GPU** plutôt que x264 logiciel.

| Encodeur | GPU requis | Qualité 2026 | Impact CPU |
|---|---|---|---|
| **NVENC H.264** | NVIDIA GTX 10xx+ | ⭐⭐⭐ | ~2 % |
| **NVENC HEVC** | NVIDIA RTX 20xx+ | ⭐⭐⭐⭐ | ~2 % |
| **NVENC AV1** | NVIDIA RTX 40xx | ⭐⭐⭐⭐⭐ | ~2 % |
| **AMF H.264** | AMD RX 500+ | ⭐⭐⭐ | ~2 % |
| **AMF AV1** | AMD RX 7000 | ⭐⭐⭐⭐⭐ | ~2 % |
| **x264 Fast** | Tout CPU (8+ cœurs) | ⭐⭐⭐⭐ | 8-12 % |
| **x264 Medium** | CPU 16+ cœurs | ⭐⭐⭐⭐⭐ | 15-20 % |

En 2026, **NVENC AV1 sur RTX 4000** offre une qualité comparable à x264 *slow* avec moins de 3 % d'impact CPU — une révolution pour le single PC streaming [Source 5].

### Paramètres OBS optimisés pour single PC

Voici les réglages OBS recommandés pour un PC gaming unique en 2026 :

**Paramètres de sortie (Output Settings) :**
- Encodeur : NVENC AV1 (RTX 40xx) ou NVENC H.265 (RTX 20/30xx)
- Bitrate : 6000 kbps (Twitch), 8000-12000 kbps (YouTube)
- Keyframe Interval : 2 secondes
- Preset : **P5 (Balanced)** pour RTX 40xx, **Quality** pour RTX 30xx
- Tuning : **High Quality**
- Multipass : **Two Pass (Quarter Resolution)**

**Paramètres vidéo :**
- Résolution de base : 1920×1080
- Résolution de sortie : 1920×1080 (ou 1280×720 si le bitrate est limité)
- FPS : 60

**Réduction de la charge CPU :**
- Activez **Game Mode** dans Windows 11
- Désactivez les overlays inutiles (GeForce Experience, Discord, Xbox Game Bar)
- Réglez la priorité du processus du jeu sur *High* dans le Gestionnaire des tâches
- Allouez **2 cœurs CPU dédiés à OBS** via les affinités de processus (option avancée)

### Gestion de la mémoire et du VRAM

Pour les jeux comme *Microsoft Flight Simulator 2024* ou *Avatar: Frontiers of Pandora* qui consomment 10-16 Go de VRAM, assurez-vous que :

- Votre GPU dispose d'au moins **12 Go de VRAM** (RTX 4070 minimum recommandé)
- Le XMP/EXPO est activé dans le BIOS pour exploiter la RAM à sa fréquence nominale
- Les paramètres graphiques du jeu laissent **10-15 % de ressources libres** pour OBS (baissez les textures d'un cran si nécessaire)

## 🛠️ 5. Configuration Logicielle Complète OBS pour 2026

### Scènes et sources recommandées

Que vous soyez en dual PC ou single PC, une bonne organisation des scènes OBS est indispensable :

- **Scène "Live Gaming"** : capture de jeu (Game Capture ou NDI Source), webcam, overlay HUD, alertes Streamlabs
- **Scène "Starting Soon"** : animation d'attente + musique
- **Scène "BRB"** : fond animé, timer de retour
- **Scène "Just Chatting"** : webcam plein écran + chat visible

### Plugins indispensables en 2026

| Plugin | Utilité | Lien |
|---|---|---|
| **obs-ndi** | Connexion dual PC via réseau | GitHub obsproject |
| **StreamFX** | Effets visuels avancés (blur, glow) | GitHub Xaymar |
| **Move Transition** | Animations fluides entre scènes | GitHub exeldro |
| **Source Clone** | Dupliquer sources sans overhead | GitHub exeldro |
| **Advanced Scene Switcher** | Changement automatique de scènes | GitHub WarmUpTill |

### Optimiser le réseau pour le streaming

Un upload insuffisant est la première cause de qualité dégradée. Vérifiez que :

- Votre débit montant est **au moins 2× votre bitrate** de stream (ex: 12 Mbps montant pour streamer à 6000 kbps) [Source 6]
- Vous utilisez une **connexion Ethernet filaire** (jamais le Wi-Fi pour le PC streaming)
- Le **Quality of Service (QoS)** de votre routeur priorise le trafic de stream
- Vous choisissez le **serveur Twitch Ingest** le plus proche via *twitch.tv/broadcast/speedtest*
